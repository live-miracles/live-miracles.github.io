Goryu runs as a single process. Each release publishes one archive, goryu-linux-x86_64.tar.gz, containing the binary and the shared libraries it needs (libsrt 1.5.6 built with bonding, OpenSSL's libcrypto, libstdc++, libgcc), so it does not depend on the host's libsrt.

Download

curl -fsSL -o goryu.tar.gz https://github.com/live-miracles/goryu/releases/latest/download/goryu-linux-x86_64.tar.gz
mkdir goryu && tar -xzf goryu.tar.gz -C goryu

Each release also publishes checksums.sha256. To verify a download, fetch it next to the archive and run sha256sum --check checksums.sha256, or check the build attestation with gh attestation verify goryu.tar.gz --repo live-miracles/goryu (needs a recent GitHub CLI; it prints nothing and exits 0 when the check passes outside a terminal, so use --format json to see the details).

The archive unpacks to bin/goryu and lib/. To pin a version, replace latest/download with download/vX.Y.Z. Check what you have with:

LD_LIBRARY_PATH=goryu/lib goryu/bin/goryu --version

Run

Write a goryu.json, then:

LD_LIBRARY_PATH=goryu/lib goryu/bin/goryu goryu.json
curl http://127.0.0.1:8081/status

Set LD_LIBRARY_PATH on the goryu command only, as above. Exporting it for the whole shell makes other tools (curl, for one) load the bundled libcrypto and fail.

systemd

A minimal unit, assuming the archive is unpacked to /opt/goryu and the config is at /etc/goryu/goryu.json:

[Unit]
Description=Goryu SRT bonding relay
After=network-online.target
Wants=network-online.target

[Service]
Type=simple
Environment=LD_LIBRARY_PATH=/opt/goryu/lib
ExecStart=/opt/goryu/bin/goryu /etc/goryu/goryu.json
Restart=always
RestartSec=2
LimitNOFILE=1048576
NoNewPrivileges=true
PrivateTmp=true

[Install]
WantedBy=multi-user.target

Add User= and Group= to run it as an unprivileged account; the input port is above 1024 and needs no special privileges. Goryu only reads its config at startup, so restart the service after changing goryu.json.

Firewall

Open the encoder-facing port (input_port) for UDP. The status port is bound to 127.0.0.1 and must stay closed to the network.

Bunryu

If you use Bunryu you do not install Goryu by hand: Bunryu's installer downloads a pinned release and sets up goryu.service, and its Docker image bundles it.
