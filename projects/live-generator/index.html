Bulk-schedule YouTube live broadcasts straight from a Google Sheet.

Fill in a few rows, click one button, and Live Generator creates the broadcasts on YouTube and binds each one to the stream key you picked.

Overview

Live Generator is a Google Apps Script project that you attach to a Google Sheet. It adds a sidebar that signs in to your YouTube account and turns spreadsheet rows into scheduled YouTube live broadcasts. It is built for teams that run many streams on a regular basis, such as daily satsangs, recurring events and multi-camera setups. For those teams, creating each broadcast by hand in YouTube Studio is slow and error-prone.

Features

  • Bulk scheduling. Select any number of rows and schedule them all at once.
  • Stream key sync. One click pulls every stream key from your YouTube channel into the YT Keys sheet.
  • Automatic binding. Each broadcast is bound to the stream key named in the row's Key ID column.
  • Row validation. Dates, times, visibility and boolean options are checked before anything is sent to YouTube, and errors name the offending row.
  • Smart defaults. If you leave Year, Month, Day or Hour empty, the current date and time are used.
  • Visual feedback. A successfully scheduled row gets its Broadcast ID filled in and highlighted. A failed row is highlighted red.
  • Activity log. The sidebar shows a timestamped log of every action and error.
  • Full control. Set visibility, DVR, auto-start, auto-stop and latency per broadcast.

Requirements

  • A Google account whose own (main) YouTube channel, the one created automatically with that account, is enabled for live streaming. Branded channels are not supported. See Which YouTube channel is used.
  • A Google Sheet to hold the schedule.

[!IMPORTANT] Live Generator works only with the main YouTube channel of the Google account you are signed in with, the one created with that email address. It does not work with Brand Accounts (branded channels), even if you are a manager or owner of one. See Which YouTube channel is used.

Setup

1. Prepare the spreadsheet

Open a Google Sheet and create two tabs with these exact names.

YT Schedule has one broadcast per row. Row 1 must contain these headers:

Column Required Description
Title Yes Broadcast title shown on YouTube.
Year No 2000-2100. Defaults to the current year.
Month No 1-12. Defaults to the current month.
Day No 1-31. Defaults to the current day.
Hour No 0-23. Defaults to the current hour plus 2.
Minute No 0-59. Defaults to 0.
Visibility Yes public, unlisted or private.
Key ID Yes The stream ID from the YT Keys tab.
DVR No true or false. Enables DVR (rewind) for viewers. Defaults to false.
Auto Start No true or false. Starts the broadcast when the stream begins.
Auto Stop No true or false. Ends the broadcast when the stream stops.
Latency No normal, low or ultraLow.
Broadcast ID Auto Leave empty. Filled in by the script. A row that already has one is rejected with an error.

YT Keys is filled in automatically by the sidebar. Add these headers in row 1, in this order:

A B C D
ID Channel ID Title Key

2. Install the script

  1. In the sheet, go to Extensions → Apps Script.
  2. Copy the contents of the project files into the editor:
    • Code.js
    • YouTube.js
    • Sidebar.html (create it with + → HTML and name it Sidebar)
  3. Enable the YouTube API. Either:
    • open Project Settings, tick Show "appsscript.json" manifest file in editor, and paste in the contents of appsscript.json, or
    • click Services (+) in the editor, choose YouTube Data API v3 and keep the identifier YouTube.
  4. Save the project, then reload the spreadsheet.

3. Authorize

Open Extensions → Live Generator → Show Sidebar. Google will ask you to authorize the script the first time. Approve the requested permissions with the account that owns your YouTube channel.

Usage

  1. Open the sidebar and check that your email and channel are shown at the top.
  2. Click Update Stream Keys to load your stream keys into YT Keys. Run this again whenever you create or change a key on YouTube.
  3. In YT Schedule, fill in your rows. Use the ID column from YT Keys for Key ID.
  4. Select the rows you want to schedule, then click Schedule Selected Rows.
  5. Check the Broadcast ID column and the sidebar log. Broadcasts also appear in YouTube Studio under Content → Live.

[!TIP] Select several rows at once to schedule a whole week of streams in one click.

Limitations

  • Main channel only. Only the YouTube channel tied to the signed-in Google account is supported. Brand Accounts are not, even if you have access to them (see below).
  • Time zone is fixed to IST. Start times are sent with a +05:30 offset and appsscript.json sets the project time zone to Asia/Kolkata. To use another zone, change the offset in insertBroadcast() in YouTube.js and the timeZone in appsscript.json.
  • Up to 50 stream keys are fetched per refresh.
  • API quota. Scheduling is subject to your YouTube Data API daily quota.

Which YouTube channel is used

The script calls the YouTube API as the Google account that authorizes it, and Apps Script's YouTube advanced service always acts on that account's own main channel. It cannot switch to a branded channel, and it does not offer a channel picker.

  • Works: the channel that was created automatically with your Google account (the sidebar shows its name as Channel).
  • Does not work: a branded channel that you can switch to in YouTube, such as a channel created for an organization or event and shared with you as a manager or owner.

If your streams live on a branded channel, this tool cannot schedule them. Check the Channel name in the sidebar: if it is not the channel you expect, you are signed in with the wrong account.

Project structure

File Purpose
Code.js Menu, sidebar, sheet logic, row validation and formatting.
YouTube.js Thin wrappers around the YouTube Data API v3 live endpoints.
Sidebar.html Sidebar UI and client-side handlers.
appsscript.json Apps Script manifest: runtime, time zone and enabled services.
