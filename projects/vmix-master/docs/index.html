vMix scripts

  • Overview: what the scripts are, how to add them to vMix, and which one to use
  • Slave: follow a master by input number, including playback position
  • NameSlave: follow a master by input name
  • PreviewNext: put the next input in preview after each transition
  • Translator: lower the program audio while a translator speaks
  • AutoGain: keep a microphone out of clipping and not too quiet
  • AudioFade: fade media audio in and out on transitions
  • DurationTimer: show the time left of the current input in a title
